## 2. Methodology & Zero-Guess Safety Policy

Every file was inspected against 20 strict safety criteria:
1. Static and dynamic import analysis across frontend and backend.
2. Route registration in `react-router-dom` and FastAPI `APIRouter`.
3. Database migration history in Alembic (`backend/alembic/versions/`).
4. Package and maintenance scripts in `package.json` and `scripts/`.
5. Environment variables and runtime configuration (`.env`, `config.py`, `vite-env.d.ts`).
6. Static assets in `public/` and `src/assets/`.
7. Test suites in `backend/tests/` and `frontend/src/tests/`.

> [!IMPORTANT]
> **ZERO-GUESS DELETION POLICY**: Only HIGH CONFIDENCE files belonging strictly to Category C (regenerable caches/logs) and Category D (unreferenced template boilerplate) are proposed for removal. All database migrations, seeder scripts, data manifests, active components, stores, routes, and tests are strictly PRESERVED.
